## Supported Distributions

- Windows GUI ZIP with `pasta-gui.bat`
- Linux GUI ZIP with `pasta-gui.sh`
- CLI ZIP with `pasta-cli.bat` and `pasta-cli.sh`

## Basic CLI Usage

```bash
java -jar pasta-cli-1.4.4.jar path/to/plugin-or-directory --rights-confirmed
```

Patched output is written to `patched-plugins/`.
