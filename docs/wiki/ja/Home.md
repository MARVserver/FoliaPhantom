## pasta とは

**pasta** は、従来の Bukkit プラグインを Folia のリージョン単位マルチスレッド実行モデルへ適応させるためのバイトコード変換ツールキットです。コンパイル済みのプラグイン JAR を書き換えるため、プラグインのソースコードは必要ありません。

利用方法は複数あります。

- **Browser** — 静的 Web アプリ上でローカルにドラッグ＆ドロップ変換。
- **GitHub Actions** — リポジトリの Action を使って CI 内で成果物を変換。
- **CLI** — バッチ処理やスクリプトからの変換。
- **GUI** — JavaFX ベースのデスクトップ操作。
- **Server plugin** — Paper/Bukkit 互換サーバー環境からプラグインを変換。

## 安全性の境界

変換に成功しても、その Bukkit プラグイン全体が Folia 上で完全に安全であることを証明するものではありません。pasta は既知のスケジューラ呼び出しやスレッド依存処理を変換できますが、プラグイン固有の共有可変状態などは残る可能性があります。

本番導入前に、必ずステージング環境で変換済みプラグインを検証してください。

## Browser 版のプライバシー

Browser 版は CheerpJ を通してパッチャーをローカル実行します。プラグイン JAR の内容を pasta の変換サービスへアップロードする設計ではありません。

## 主な機能

- ソースコード不要のバイトコードレベル変換。
- 書き換え後に無効となる JAR 署名の除去。
- 必要に応じた `folia-supported: true` メタデータの付与。
- 変換済みスケジューラ呼び出し向けランタイムブリッジの同梱。
- 高速な事前スキャンと、対応環境での並列変換。
- Browser / CLI / GUI / Server plugin / GitHub Actions で共通の変換コアを利用。

## 必要環境

Java ベースのビルドおよび配布形態では **JDK 21+** を使用してください。プロジェクトのビルドには Maven 3.8+ が必要です。pasta 自身のクラスは現在 Java 17 バイトコードを対象にしていますが、現行 Paper 依存関係を解決するためビルド JDK は Java 21 以上が必要です。
