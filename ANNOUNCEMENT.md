# お知らせ / Announcement

**2026-09-15**

## pasta の運営について

pasta は、現在 **MARVserver のプロジェクトではありません**。今後はこのリポジトリを中心に、独立したオープンソースプロジェクトとして開発・保守していきます。

この変更は、これまでの開発や貢献を否定するものではありません。pasta を支えてきたすべてのコード、アイデア、報告、検証、フィードバックに敬意を払いながら、これからはより開かれた形でプロジェクトを育てていきます。

私たちはオープンソースを応援します。ソフトウェアは、誰でもコードを確認でき、学び、改善し、再利用し、必要であればフォークできることで、より強く、長く生きるものだと考えています。pasta もその一員として、透明性のある開発と知識の共有を大切にします。

バグ報告、機能提案、ドキュメント改善、検証結果、Pull Request、フォーク、派生プロジェクトなど、さまざまな形の参加を歓迎します。小さな貢献も含め、コミュニティによる改善がオープンソースを前に進めます。

これからも pasta を、特定の組織のためだけではなく、必要とする人が自由に利用し、調べ、改善できるプロジェクトとして育てていきます。

---

## Project status

pasta is **no longer a MARVserver project**. From now on, it is developed and maintained independently around this repository as an open-source project.

This change does not diminish the work and contributions that came before it. We appreciate the code, ideas, testing, reports, and feedback that helped shape pasta, and we intend to continue the project in a more open and transparent way.

We support open source. Software becomes stronger when people can inspect it, learn from it, improve it, reuse it, and fork it when their needs differ. pasta aims to contribute to that ecosystem through transparent development and shared knowledge.

Bug reports, feature proposals, documentation improvements, testing results, pull requests, forks, and downstream projects are all welcome. Every useful contribution, including small ones, helps move open source forward.

We will continue building pasta as a project that people can freely use, study, and improve.
