# アーキテクチャ

[日本語](日本語.md) · [はじめに](はじめに.md) · [English](Architecture.md)

## 処理パイプライン

```text
入力 JAR
  │
  ▼
JarInputStream ──► 書き換えで無効になる署名を削除
  │
  ├──────────────► plugin.yml の互換性メタデータを更新
  │
  ▼
ScanningClassVisitor
  │
  ├── 対象 Bukkit バイトコードなし ──► そのままコピー
  │
  ▼
Transformer chain
  ├─ ThreadSafetyTransformer
  ├─ WorldGenClassTransformer
  ├─ EntitySchedulerTransformer
  ├─ PlayerSafetyTransformer
  └─ SchedulerClassTransformer
  │
  ▼
ランタイムブリッジを同梱
  │
  ▼
JarOutputStream ──► patched JAR
```

## モジュール

| Module | 役割 |
| --- | --- |
| `core` | ASM visitor、変換チェーン、ランタイムブリッジ |
| `cli` | コマンドライン frontend |
| `gui` | JavaFX デスクトップ frontend |
| `plugin` | Bukkit/Paper サーバー側 frontend |
| `web` | 静的 Web アプリ用ブラウザブリッジ |

## Transformer の順序

Transformer の適用順は意図的です。後段の変換が、前段で行われた正規化に依存する場合があります。

1. `ThreadSafetyTransformer`
2. `WorldGenClassTransformer`
3. `EntitySchedulerTransformer`
4. `PlayerSafetyTransformer`
5. `SchedulerClassTransformer`

## Runtime bridge

変換済み JAR に同梱される `FoliaPatcher` は、リージョン/global/async scheduler、BukkitRunnable 型のスケジューリング、スレッド依存のブロック操作、ワールド生成互換処理、タスク追跡とキャンセルなどを実行時に適応します。

## 安全性モデル

Transformer は認識できるバイトコードパターンを書き換えられますが、任意のプラグイン内部の mutable state が Folia のスレッドモデル上で安全であることを形式的に証明するものではありません。実環境での検証が必要です。
